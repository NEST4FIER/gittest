Start mining on your phone

  1. Tap Android app above and open the download.
  2. If Android asks, allow installs from this source, then tap Install. (It isn't from the Play Store, so you may see a warning. Tap More details → Install anyway.)
  3. Open FierCoin. It starts by itself.
  4. Go to the Mining tab and tap the big button. That's it.
  5. On the Balance tab, follow the 2 safety steps: set a password and make a backup.

Start mining on iPhone

  1. On your iPhone, open the FierCoin web app in Safari.
  2. Tap the Share button, then Add to Home Screen. Open FierCoin from your Home Screen.
  3. Tap Create a new wallet, choose a password and write down your 12 words.
  4. Go to the Mining tab and tap the big button. Keep the screen on while it mines.

Apple doesn't allow mining apps in the App Store, so FierCoin for iPhone runs as a web app. Your keys stay on your phone. It mines only while the app is open on screen.

Start mining on Windows

  1. Tap Windows wallet above and run it. If Windows warns you, click More info → Run anyway.
  2. Open FierCoin Core from the Start menu.
  3. Go to Receive → Create new receiving address → Copy.
  4. Go to Window → Console and type: setgenerate true 2 YOUR_ADDRESS

Full steps are in the FierCoin guide.

One worldwide network

Like Bitcoin, every FierCoin wallet connects to other FierCoin computers by itself, and everyone shares one blockchain. There's nothing to set up: install, open, and you're on the network. That's what lets you mine together and send coins to anyone.

  • Live explorer: see every block and payment at 68-183-155-121.sslip.io.
  • Always-on seed node: 68.183.155.121:29333 (built into the apps).
  • Help the network: leave your PC wallet running. It opens your router automatically so others can connect to you, just like early Bitcoin.

Please read

  • Honest start: the founder mined most of the first coins. Read how FierCoin started.
  • No price yet. FIRC isn't sold on any exchange. It's only worth what people agree to trade it for. Nobody can promise it will gain value.
  • Keep your backup and password safe. If you lose them, nobody can get your coins back.
  • Never give your wallet password or backup file to anyone who asks for it, including anyone saying they're from FierCoin.
  • Some antivirus programs flag any app that can mine. That's expected for mining software.
